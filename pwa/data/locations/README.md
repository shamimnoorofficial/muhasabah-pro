Static geographic reference data, retrieved 2026-11-17.

Sources: https://github.com/dr5hn/countries-states-cities-database and https://github.com/nuhil/bangladesh-geocode. Licenses included alongside the data. Country files are loaded only when selected. Administrative coverage varies by country; area searches use OpenStreetMap Nominatim on explicit submission. Coordinates represent named places, not a device GPS fix.
